# Anima Prompt Studio · рабочая версия Google AI Studio

Эта версия основана на вашем рабочем экспорте `gpt1 (1).zip`. Сохранены способ запуска, SDK Gemini, подключение WebSocket, обработка ошибок среды AI Studio, ключ из Secrets, ручной ключ и выбор Gemini. Изменена генерация и отображение итогового промпта.

## Главный результат

После анализа фото или обработки текста появляется **Короткий полный промпт для Anima**. Это гибридный формат из версии Anima Prompt Studio, которая открывалась в ChatGPT:

- компактные теги для количества, узнаваемых признаков, одежды и стиля;
- естественные английские фразы для позы, принадлежности рук, контактов, ракурса и композиции;
- каждый персонаж описывается отдельно, затем их взаимное расположение и действия;
- примерно 80–140 слов для простой сцены; больше только для необходимых деталей сложной группы;
- негативный промпт учитывает риски конкретной сцены.

Основной промпт можно редактировать и копировать. Подробный промпт той же сцены теперь показан отдельным большим редактируемым полем с собственной кнопкой копирования. После результата открыт блок расшифровки, который можно свернуть; редактор тегов остаётся дополнительным раскрывающимся блоком. Отдельные SDXL/Pony/FLUX-результаты больше не генерируются. Теги являются дополнительным представлением сцены, а не ещё одной обязательной «версией» результата.

При ручной правке тегов основной текст автоматически не переписывается. Отредактируйте его в главном поле или повторно обработайте изменённый исходный текст. Короткий и подробный промпты можно редактировать отдельно; ручные правки одного поля не меняют другое.

## Подробный промпт и расшифровка

Подробный вариант ориентирован примерно на 200–400 английских слов для сцены с большим количеством деталей; для групп он может быть длиннее, а простые сцены не дополняются выдуманными деталями ради объёма. Он описывает ту же сцену, что короткий вариант, последовательно раскрывая камеру, композицию, внешность и выражение лица каждого персонажа, положение в кадре, конструкцию одежды, аксессуары, каждую видимую часть позы, контакты, окружение, свет, стиль и палитру.

Расшифровка на русском теперь содержит отдельные поля торса, головы, таза, обеих рук и кистей, обеих ног, опоры и распределения веса. Одежда и аксессуары перечисляются отдельно. Скрытые или незаданные детали отмечаются явно; анатомическая сторона не назначается наугад. Все значимые распознанные детали переносятся в подробный промпт, кроме неопределённых наблюдений, которые не должны превращаться в факты.

## Выбор моделей

**Gemini** — сервис, который анализирует фото и пишет текст. Его выбор, загрузка списка и ручной ID остались в исходном рабочем блоке настройки ключа.

**Anima Base / Aesthetic / Turbo** — модель, для которой составляется промпт. По умолчанию Aesthetic. В Base допустим подходящий quality/score-префикс, Aesthetic не полагается на score-теги, Turbo получает более компактный текст. Префиксы Pony вроде `score_9, score_8_up, source_anime` не используются.

В «Точность и свобода деталей» задаются сохранение позы, одежды, композиции, взаимодействий и свобода деталей (0–100). Свобода касается незаданных деталей окружения/стиля, а не замены персонажей или принадлежности конечностей. Добавленные детали перечисляются в разборе. В режиме строгой обработки текста незаданные позы и детали не выдумываются.

## Работа

1. Обновите файлы существующего рабочего проекта из архива целиком. Сохраните секрет `GEMINI_API_KEY` в AI Studio.
2. Выполните `npm install`, полностью перезапустите Preview через `npm run dev`.
3. Выберите Gemini и нужный вариант Anima.
4. Загрузите PNG/JPEG/WebP до 8 МБ и нажмите «Разобрать фото и собрать промпт Anima» либо напишите сцену и нажмите «Собрать промпт Anima».
5. Скопируйте главный промпт и негативный в генератор изображения. Это приложение само изображения не генерирует.

Поле ключа можно оставить пустым для секрета среды; введённый ключ имеет приоритет. Ключ хранится до закрытия вкладки. В архиве ключей нет.

Фото → анализ → сборка идут в одном запросе Gemini. Используются правила исходного hosted-компилятора, адаптированные к JSON-схеме этого проекта. Это не обещание одинакового текста при каждом запуске: результат зависит от выбранного Gemini, фото и входного текста.

## Помощник текста

Блок «Помочь написать промпт» сохранён. «Поправить формулировку» оформляет ваши слова без новых деталей; «Дополнить идею» предлагает совместимые дополнения с сохранением замысла. Вы сначала просматриваете вариант, затем вставляете его в исходное поле и собираете главный Anima-промпт. Помощник текста не анализирует прикреплённое фото.

## Подключение и запуск

Node.js 22+.

```sh
npm install
npm run dev
```

Рабочая цепочка: React → `/api/*` → Express → `@google/genai` → Gemini. `server.ts` объединяет HTTP и HMR на одном сервере, как в вашем рабочем экспорте. `vite.config.ts` сохраняет API plugin для запуска через Vite. `server/api.ts`, `server/gemini-sdk.ts` и `src/lib/api.ts` сохранены из рабочего экспорта, включая обработку Warmup.

Для локального запуска скопируйте `.env.example` в `.env` и задайте `GEMINI_API_KEY`; не публикуйте `.env`. В production:

```sh
npm run build
npm start
```

Статический режим сохранён:

```sh
npm run build:pages
npm run preview:pages
```

В статическом режиме пользователь вводит свой ключ, запрос идёт из браузера прямо в Google. Эта сборка заменяет `dist`, поэтому перед серверным production-запуском снова выполните `npm run build`. В этом экспорте нет автоматической публикации Pages; для текущей задачи основной сценарий — AI Studio.

## Изменённые части

- `src/lib/anima-instructions.ts` — правила компиляции из hosted Anima Prompt Studio.
- `src/lib/gemini.ts` — схема с `hybridPrompt`, инструкции, вариант Anima и параметры точности.
- `src/components/PromptOutput.tsx` — один основной результат, негативный и раскрывающийся подробный вариант.
- `src/components/AnimaSettings.tsx` — вариант Anima и параметры точности.
- `src/App.tsx` — новый основной результат и дополнительные блоки.
- `src/components/AnalysisPanel.tsx` — анализ без дублирования подробного промпта.

## Проверка

```sh
npm run lint
npm test
npm run build
npm run build:pages
```

Тесты используют подставные ответы Google: проверяют SDK, передачу модели/фото, схему основного результата, Anima-вариант и точность, ошибки, список моделей, помощник текста и запуск API. Они не оценивают качество реального ответа Gemini. Реальный запрос из вашего аккаунта AI Studio здесь не выполнялся.
